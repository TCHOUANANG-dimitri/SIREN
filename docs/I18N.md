# Internationalisation (FR / EN)

## Organisation

- Catalogues : `src/i18n/locales/<fr|en>/<domaine>.json` — `common`, `auth`,
  `children`, `alerts`, `sharing`, `map`, `community`, `settings`, `legal`,
  `notifications`, `errors`. Tous les domaines sont fusionnés dans un seul espace
  de noms (`src/i18n/resources.ts`) : un domaine est un fichier, pas un préfixe.
- Clés sémantiques : `settings.security.twofaLabel`, `apiErrors.reasons.self_invite`.
- Textes juridiques longs : hors JSON, dans `src/legal/content/<langue>.ts`
  (une langue par fichier, versions dans `src/legal/registry.ts`).
- Emails et push : rédigés par le serveur (voir plus bas), avec les mêmes termes.

## Langue affichée — règle de priorité

1. Choix fait dans SIREN sur ce téléphone (Réglages → Langue), mémorisé localement.
2. Sinon, langue du compte (`users.langue`, appliquée à la connexion).
3. Sinon, langue du téléphone (français si elle n'est ni `fr` ni `en`).

Le choix est envoyé au serveur (`PATCH /users/me {langue}`) : les notifications
et emails **futurs** partent dans cette langue. S'il n'a pas pu l'être (hors
connexion), l'app le dit et le renvoie à la session suivante
(`reconcileAccountLanguage`). Les notifications déjà reçues gardent leur texte.
Code : `src/i18n/language.ts`.

## Règles d'écriture

- Aucune phrase construite par concaténation : variables `{{nom}}` et pluriels
  i18next (`_one` / `_other`) — ex. `sharing.slotsLeft_one|_other`.
- Dates, heures, nombres : `src/utils/format.ts` (locale `fr-FR` / `en-GB`).
- Mêmes variables dans les deux langues (vérifié par test et par script).
- Messages d'erreur : l'app n'affiche jamais le texte du serveur ; elle traduit
  le motif `detail.code` (`apiErrors.reasons.*`) ou le statut (`apiErrors.*`).
- Libellés d'accessibilité traduits comme le reste.
- Noms de langues (« Français », « English ») : volontairement non traduits
  (`LANGUAGE_AUTONYMS`).

## Vérification

`npm run i18n:check` (`scripts/i18n-check.mjs`) :

| Contrôle | Niveau |
|---|---|
| `MISSING_TRANSLATIONS` — clé absente d'une langue ou utilisée sans exister | erreur |
| `PLACEHOLDER_MISMATCHES` — variables différentes entre FR et EN | erreur |
| `EMPTY_TRANSLATIONS` | erreur |
| `HARDCODED_UI_TEXT` — texte d'interface en dur (heuristique) | erreur |
| `UNUSED_KEYS` — clés jamais référencées | avertissement (`--strict` : erreur) |

Les tests Jest `src/i18n/__tests__/*` vérifient aussi la parité des clés, les
variables et l'absence de valeurs vides.
