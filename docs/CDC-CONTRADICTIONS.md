# Contradictions entre les CDC (Application, IA, Dispositif) et avec le code

Aucune n'a été « réconciliée en silence ». Pour chacune : ce qui a été fait dans
le code en attendant, et la décision attendue. **VH** = validation humaine requise.

| # | Contradiction | Source A | Source B | Impact / risque | Ce qui est fait en attendant | Décision attendue (VH) |
|---|---|---|---|---|---|---|
| C1 | **Capteur cardiaque** | CDC IA §2 : module « Anomalie cardiaque » (fréquence + variabilité) | CDC Dispositif §2 : GPS, GSM SIM800L, BLE, MPU6050 — aucun capteur cardiaque | Module IA sans donnée d'entrée ; faux sentiment de couverture | Rien d'implémenté ; entrée déclarée manquante dans `docs/contrats/ia-v1.md` | Ajouter un capteur (coût, autonomie, port au corps) **ou** retirer le module du périmètre V1 |
| C2 | **Audio** | CDC IA : événements sonores (YAMNet) ; CDC App : écoute encadrée, étiquettes seules | CDC Dispositif : micro « envisagé » si risque élevé, sans spécification ; aucun cadre juridique | Données sensibles d'un mineur, risque légal | Écoute bloquée par défaut (`AUDIO_ENABLED=false` serveur, flag `audio` app), motif obligatoire, journal | Avis juridique ; décision matériel (micro oui/non) |
| C3 | **Caméra** | CDC Dispositif : photos au retrait du boîtier | Aucun CDC App/IA ne traite ces photos | Collecte d'images non encadrée | Rien d'implémenté | Garder ou retirer ; cadre juridique |
